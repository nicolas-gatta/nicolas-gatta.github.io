# Workshop materials

Locally hosted 1K diffuse, OpenGL normal and roughness maps from Poly Haven:

- [Garage Floor](https://polyhaven.com/a/garage_floor) by Jenelle van Heerden.
- [Painted Worn Brick](https://polyhaven.com/a/painted_worn_brick) by Dimitrios Savva.

Both materials are [CC0](https://polyhaven.com/license). Original download URLs, authors and checksums are recorded in `attribution.json`. The scene repeats these maps at workshop scale; diffuse maps use sRGB and data maps retain linear color space.
